# 界面设计说明

本次按 Anthropic 的 [frontend-design skill](https://github.com/anthropics/skills/tree/main/skills/frontend-design) 优化现有 WPF 界面。设计目标是保持本地资源库简洁，重点改善控件形状、表面层次与操作反馈。

## 布局与形状

- 保留项目导航、资源列表、详情编辑三栏结构，分栏宽度可拖动调整。
- 搜索与当前资源集合放在同一区域。窗口顶部保留应用名称、添加、刷新与语言选择，避免英文界面在较小窗口中挤压搜索。
- 面板使用 10 像素圆角，导航选中区域使用 8 像素圆角，按钮与输入框使用 6 像素圆角。状态以小胶囊显示，层级通过用途区分。
- 材质感来自细边框、轻微的表面明暗变化与资源列表的柔和阴影。阴影只作用于面板背板，正文保持清晰；没有使用系统背景模糊。
- 图标用本地矢量路径绘制，文件与文件夹、全部资源与最近打开有不同标识。不增加联网字体、图标依赖或外部界面框架。
- 中文采用 Microsoft YaHei UI，英文回退 Segoe UI，确保离线和 Windows 10 / 11 环境中的可读性。

## 操作反馈

按钮悬停时上移 1 像素，耗时 120 毫秒；移开时 100 毫秒复位。按压加深表面反馈，选中导航淡入耗时 140 毫秒，勾选反馈耗时 120 毫秒。动画由操作触发，没有自动循环。

动画启动条件读取 Windows `SystemParameters.ClientAreaAnimation`；关闭系统动画后，新建的控件不启用这些动画。键盘操作有可见焦点，禁用操作降低不透明度。输入框仍支持多行编辑，详情区与资源列表保持滚动。

## 后续主题扩展

`App.xaml` 集中定义 `CanvasColor`、`SurfaceColor`、`RaisedColor`、`LineColor`、`InkColor`、`MutedColor`、`AccentColor` 和语义状态颜色。控件以动态资源引用颜色，形状、字体与交互模板独立于配色。

本次仍采用单套浅色配色。深色、浅色与自定义主题的选择、保存以及主题间对比度校验留待后续实现；动态资源结构本身不代表这些设置已经上线。

## 功能边界

本次不改变资源登记、搜索、SQLite、项目关系、文件打开、真实重命名或修复路径的业务逻辑。新建项目与选择项目弹窗使用相同的控件体系，确认、取消与输入验证保持原行为。
