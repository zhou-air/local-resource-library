# 资源拖拽、剪贴板与撤销

资源操作管理库内引用和项目关联，原文件与文件夹保持在原处。详情栏保留别名、简介、笔记和路径，项目归属通过以下操作管理；数据库仍保留 ProjectItem，MCP 仍使用永久 Item ID 与 Project ID。

| 操作 | 结果 |
| --- | --- |
| Ctrl + 单击 / Shift + 单击 | 增减选择 / 连续选择 |
| Ctrl + A / Esc | 全选当前列表 / 清除选择和剪切状态 |
| 从空白处拖动鼠标 | 矩形框选，Ctrl 框选保留原有选择；边缘自动滚动 |
| 拖动选中的一个或多个资源到项目 | 加入目标项目，保留已有归属 |
| Shift + 拖动到项目 | 从拖动开始时的项目移到目标项目，其他项目归属保留 |
| Ctrl + C / Ctrl + X | 复制 / 剪切选中资源引用 |
| Ctrl + V | 粘贴到当前项目；项目右键「粘贴」可直接指定目标 |
| Ctrl + Z / Ctrl + Y | 撤销 / 重做；工具栏和右键菜单也提供命令 |

八种视图共用选择与资源服务。从资源条目开始拖动属于资源拖拽，从空白处开始属于框选。剪切条目半透明显示，粘贴成功、Esc 或更换剪贴板内容后恢复。文本输入框保持 Windows 原有复制、剪切、粘贴和撤销快捷键。

普通项目、置顶项目和未分组区域中的具体项目均可接收资源。分组标题不接收资源；悬停在折叠分组上约 650 毫秒可展开。在「全部资源」、最近打开或路径失效等没有来源项目的视图中剪切，粘贴仅加入目标项目。粘贴到已包含资源的项目不会重复添加。

外部剪贴板支持 Explorer 复制或剪切的文件/文件夹、绝对路径、多行路径以及有效 HTTP/HTTPS URL。多个路径每行一个，可保留 Explorer「复制文件地址」产生的外围双引号。重复目标复用原 Item 和元数据。无法识别的文本会在状态栏提示；无效或无法导入的资源使本批导入全部回滚。Explorer 的剪切标记不会触发真实文件移动或删除。

内部剪贴板仅含版本、资源库身份、Item ID、来源 Project ID、剪切标记和操作标识；同时提供文本路径以便在其他程序中粘贴。资源库之间不使用对方的内部 ID，只能从公开路径或 URL 导入。

撤销历史仅属于当前运行会话，最多 100 步。批量归属操作、剪贴板导入、资源记录删除，以及项目/分组创建、删除、重命名、颜色和分组变更均按完整操作记录。撤销复制仅移除本次新增的关联；撤销移动恢复来源；撤销删除恢复原 ID 与关联。新变更清除重做历史，无实际变化的重复操作不增加历史。真实文件打开、改名、路径恢复和 Windows 文件系统操作不属于撤销范围。

界面和 MCP 共用 Core 中的 TransferResources、ChangeResourceProjectsBatch 和 ImportReferences。每次批量操作及每次撤销/重做均使用 SQLite 事务。关联版本表及 SQLite 触发器记录关联变化，即使外部先删除再加回同一关联也能拒绝旧撤销；历史冲突时清除过期历史，保留当前数据。原有表、结构版本及 Item/File/Project ID 保留。

本次按用户选择只修改源码，dist 与已安装 MCP 运行版保持原版本。功能检查使用临时文件和独立数据库，不向个人资源库写入测试数据。
