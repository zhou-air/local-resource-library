# 本地资源库 · Local Resource Library

[English](README.en.md)

基于 WinUI 3 的 Windows 本地资源库：为文件、文件夹和网址添加别名、说明、笔记与项目归属，支持本地搜索、八种查看方式、自然排序和中英文界面。

**文件仍保留在原来的位置。** 添加文件或文件夹保存绝对路径，并在 Windows 支持时保存文件的卷标识与 File ID，不复制、不移动文件，也不保存文件内容。网址使用同一个 Item 模型和 SQLite 资源库，保存 URL、说明及可选网站图标。资源记录有独立且永久的 Item ID，不以路径作为身份。同一个资源可属于多个逻辑项目，所有项目共用同一条资源记录。项目现仅保留 WinUI 3 桌面界面。

资源框选、批量拖拽、复制/剪切/粘贴与 100 步会话撤销已接入；使用方法见[资源交互说明](docs/resource-interactions.md)。

## AI Agent / MCP 接入

独立的 `LocalResourceLibrary.Mcp` 使用标准 stdio 协议，让 Codex 等客户端搜索和管理同一资源库中的文件、文件夹与网址，不需要启动 WinUI。支持局部元数据更新、逻辑项目和多项目归属；批量修改采用预览令牌、客户端确认和整批事务提交。

运行 `powershell -ExecutionPolicy Bypass -File .\scripts\publish-mcp.ps1`，将生成目录中的 `codex-mcp.toml` 内容追加到 Codex 配置即可使用。完整配置、工具参数、并发边界和测试命令见 [MCP 接入说明](docs/mcp.md)。MCP 写入后，在 WinUI 点击「刷新资源和状态」或按 F5 加载变更；保存本地草稿时只更新实际编辑字段，同字段冲突会拒绝保存并保留草稿。

## 已提供的功能

- 通过文件选择、文件夹选择或拖放添加资源；已登记的相同路径复用现有记录。
- 通过「添加资源 → 添加网址」输入或粘贴 HTTP/HTTPS URL，自动获取标题、Description 和 Favicon，失败仍可收藏；网址可加入多个项目。
- 分别维护别名、说明和笔记；别名作为资源库中的首选显示名称，不改动真实文件名。
- 创建逻辑项目，通过资源拖拽、复制、剪切和粘贴管理归属；一个资源可以属于多个项目。
- 右键项目重命名，只更改项目显示名称，保留项目说明、资源关联和磁盘文件。
- 使用单层项目分组整理侧边栏；项目可拖动排序和跨组移动，未分组项目单独显示。删除分组保留项目和资源，展开状态在本机记住。
- 右键项目设置柔和预设颜色、所属分组或打开项目属性；仅线框文件夹图标着色，名称、数量和选中背景沿用原主题。置顶项目保留独立区域。
- Project ID 和 Group ID 为永久只读身份；项目属性的高级信息中可复制 Project ID。MCP 可按名称查询候选，所有项目及归属操作使用 ID。
- 启动后默认显示右下角托盘图标；点击窗口 × 隐藏到托盘，点击图标恢复，右键「退出资源库」完全退出。
- 删除项目；通过资源右键菜单、工具栏或 `Delete` 删除单个或多个资源记录，保留原文件。项目内右键还可仅移除项目归属。
- 支持 `Ctrl` 多选、`Shift` 连续选择和 `Ctrl+A` 全选；多选时可批量删除或复制路径、网址。
- 在别名、真实文件名或网站域名、路径或 URL、说明、笔记和项目名称中执行本地文本搜索。
- 按全部资源、最近打开、路径失效和项目筛选。
- 双击打开资源；打开所在位置、复制路径；记录打开次数与最近打开时间。
- 双击网址使用 Windows 默认浏览器打开；右键可修改网址或复制网址，详情可修改完整 URL、别名、说明和笔记；删除收藏只删除库内记录。
- 打开文件时，若原路径已失效，可凭已保存的卷标识与 File ID 恢复同一卷内的原文件，自动更新路径并保留原有别名、说明、笔记与项目归属。
- 文件显示 Windows 文件关联图标，网址优先显示已保存的 Favicon，失败使用默认网页图标；三类资源共用超大图标、大图标、中等图标、小图标、列表、详细信息、平铺和内容八种视图。
- 按名称、修改日期、类型、大小或上次打开排序，可选择递增、递减和文件夹优先；名称使用 Windows 自然排序。
- 调整导航栏和详情栏宽度；查看方式、排序、栏宽在本机保存；界面语言自动跟随系统。
- SQLite 本地持久化；中文与英文界面；未保存修改的保存、放弃和取消提示。

## 运行

支持 64 位 Windows 10 / Windows 11 桌面环境。发布包包含所需的 .NET 与 Windows App SDK 运行依赖。

1. 完整解压发布文件夹，保留其中的全部文件。
2. 双击 `LocalResourceLibrary.WinUI.exe`。
3. 添加文件、文件夹或网址，填写说明，并按需要加入项目。

不需要账号。启动和浏览资源时不发起后台网络请求；用户添加或修改网址时会获取网页信息。应用不提供云同步、遥测或后台网络服务；打开资源时调用的外部程序可能有自己的联网行为。

### 常用操作

| 目的 | 操作 |
| --- | --- |
| 为资源取易懂的名称 | 编辑「别名」，不会改动真实文件名 |
| 说明资源内容和价值 | 编辑「说明」 |
| 留下个人或临时信息 | 编辑「笔记」 |
| 设置或取消项目归属 | 拖入项目，或复制/剪切后到项目粘贴；移除归属使用资源右键菜单 |
| 打开资源 | 双击资源，或使用详情中的「打开」 |
| 在资源管理器定位 | 使用「打开所在位置」 |
| 获取资源路径 | 使用「复制路径」；多选后右键可复制多条路径 |
| 收藏或修改网址 | 「添加资源 → 添加网址」；选中网址后编辑详情，或右键「编辑网址」 |
| 获取网址 | 使用「复制网址」；混合多选可复制路径与网址 |
| 删除资源记录 | 右键「删除资源」、工具栏「删除资源」或资源区 `Delete`；确认后保留原文件 |
| 仅从当前项目移出资源 | 在项目内选中资源后右键「从项目移除」 |
| 删除逻辑项目 | 右键项目「删除项目」 |
| 修改项目名称 | 右键项目「重命名项目」，输入新名称并保存 |
| 整理项目分组 | 新建分组后拖入项目；右键分组可重命名、排序、创建项目或删除 |
| 修改项目颜色和分组 | 右键项目选择颜色或所属分组，也可打开「项目属性」 |
| 获取项目永久 ID | 项目属性展开「高级信息」，复制只读 Project ID |
| 隐藏 / 恢复窗口 | 点击窗口 × 隐藏，点击右下角托盘图标恢复；再次启动也会唤回已有窗口 |
| 完全退出程序 | 右键托盘图标「退出资源库」；未保存修改会提示保存、放弃或取消 |
| 选择多个资源 | 按住 `Ctrl` 点击、`Shift` 连续选择，或使用「全选」 / `Ctrl+A` |
| 检查外部文件的可用性 | 点击「刷新资源和状态」 |
| 切换查看方式和排序 | 使用工具栏「查看」和「排序」；详细信息表头也可点击排序 |
| 切换语言 | 自动跟随 Windows 显示语言，重启应用后生效 |

修改详情后点击「保存」。切换资源、分类或从托盘退出时，未保存的修改会提示保存、放弃或取消。点击窗口 × 只隐藏，当前编辑内容继续保留。托盘图标默认常驻，可能收纳在任务栏右下角的上箭头菜单中；系统决定其在通知区域的排列位置。搜索在当前左侧分类中生效；输入多个以空格分开的词时，每个词都需要出现在该资源的某个可搜索字段中。要搜索整个资源库，请先选择「全部资源」。

添加文件夹只登记文件夹本身，不自动导入其全部内容。资源在外部移动、断开或恢复连接后，可点击「刷新资源和状态」重新检查保存的路径；刷新不会寻找新位置。失效路径的记录和说明会保留。

网址仅去掉输入首尾空白后按完全相同的文本去重；域名大小写、端口、HTTP/HTTPS、路径、参数及 `#片段` 的不同都会保留。再次添加相同网址只补充所选项目归属，不覆盖已有别名、说明、笔记或图标。

网页信息异步获取，总超时为 8 秒，覆盖页面、跳转和图标请求；部分信息或获取失败都允许保存。用户手动编辑过的别名和说明，包括主动清空的内容，不会被自动填充覆盖；编辑已有网址同样保留原内容，URL 改变后旧请求结果会被丢弃。「刷新资源和状态」不检查网站是否在线。图标保存在原 SQLite 数据库中，支持不超过 512 KiB 的 PNG、JPEG、GIF 或 ICO；无法解码时显示默认网页图标。

文件在外部改名后，直接「打开」该条目即可触发恢复：先检查原路径，原路径失效时再用已保存的文件身份定位同一卷内的原文件；找到后自动保存新路径并打开。Item ID、别名、说明、笔记和项目归属保持不变。无法恢复时标记为「路径失效」。旧资源库中路径仍有效的文件会在路径检查或打开时补存文件身份；已失效且从未保存身份的条目仍保留为「路径失效」。

选中单个资源后详情栏展开；多选时收起单个资源详情，状态栏显示已选数量。点击资源区空白、按 `Esc` 或切换左侧分类可清除选择并收起。工具栏「详细信息」可以为当前选择打开或关闭详情。拖动分隔线调整栏宽；分隔线获得键盘焦点后可用左右方向键调整。

快捷键：`Ctrl+F` 聚焦搜索，`Ctrl+S` 保存详情，`F5` 刷新资源和状态。在资源区中，`Ctrl+A` 全选当前结果，`Delete` 删除选中记录，`Enter` 打开单个选中资源，`F2` 编辑单个资源别名。

## 数据与备份

默认数据库位置：

```text
%LOCALAPPDATA%\LocalResourceLibrary\library.db
```

数据库保存资源元数据、文件身份、URL、网站图标、项目分组与关联关系，不保存文件内容或网页正文。已有结构版本 1–4 的数据库会自动升级到版本 5，保留原有项目 ID、资源与关联；旧项目默认使用主题适配颜色并归入未分组。备份数据库也不等于备份原文件。界面语言跟随 Windows 显示语言（中文系统使用中文，其他语言使用英文）；旧 `settings.json` 的语言选择不再读取。视图、排序、栏宽和分组展开状态在本机保存。同一个数据目录同时只允许打开一个 WinUI 窗口实例；MCP 可独立或同时运行，写入由 SQLite 事务协调。升级时应同时使用新版 WinUI 和 MCP，旧程序会拒绝打开较新结构的数据库。

**备份时先完全退出 WinUI 和所有 MCP 客户端/服务器进程，再复制整个 `LocalResourceLibrary` 数据目录。** 恢复时也先退出这些进程，再将备份放回原位置。迁移到另一台电脑时，需要让资源在保存的路径上可用；当前界面尚未提供路径修复。

使用独立数据目录：

```powershell
.\LocalResourceLibrary.WinUI.exe --data-dir "C:\Temp\LocalResourceLibrary-Test"
```

删除程序文件夹不会自动删除保存在本地应用数据目录中的资源库。

## 从源码构建

需要 Windows 和 [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)。首次还原、构建或发布可能需要联网下载 NuGet 依赖及运行时包；Windows SDK 构建工具由 NuGet 还原。`global.json` 选择 .NET 10 正式版 SDK，并允许使用同一主版本的更新功能带。

建议将源码放在 `C:\Dev` 等较短路径。过深目录可能导致 WinUI XAML 编译的中间路径超长。

```powershell
dotnet build .\LocalResourceLibrary.WinUI.slnx -c Release -p:Platform=x64
dotnet run --project tests/LocalResourceLibrary.Checks
dotnet run --project tests/LocalResourceLibrary.ExplorerChecks
dotnet run --project tests/LocalResourceLibrary.UrlChecks
dotnet run --project tests/LocalResourceLibrary.CoreConcurrencyChecks
dotnet run --project tests/LocalResourceLibrary.McpChecks
```

这五组检查覆盖核心行为、资源浏览模型、网址抓取及编辑草稿、共享数据库并发和真实 stdio MCP 协议，不等于完整界面、真实网站可用性或视觉验收。

发布包含运行依赖的 Windows x64 版本：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\publish-winui.ps1 -Zip
```

发布目录为 `dist/LocalResourceLibrary-WinUI-win-x64`，压缩包为同名 `.zip`。必须分发完整文件夹或完整压缩包。成功发布后默认清理本次替换的旧输出；如需保留，添加 `-KeepPrevious`。

打包源码，无需安装 Git：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\package-winui-source.ps1
```

输出为 `dist/LocalResourceLibrary-WinUI-trial-source.zip`，包含独立顶层目录、WinUI 界面、Core、检查程序、配置、文档和开发脚本。脚本排除构建缓存、数据库、用户设置及日志；按固定顺序和时间戳生成条目。成功打包后默认清理本次替换的旧源码包；如需保留，添加 `-KeepPrevious`。

本项目为个人使用。agent 完成任务后无需进行视觉校验或截图验收，只有用户明确要求时才执行；代码改动仍需相关编译和功能检查，详见 [协作约定](AGENTS.md)。

## 范围与限制

当前 WinUI 界面尚未提供真实文件重命名或手动路径修复；相关接口仍保留在 Core 中，尚未接入界面。项目属性、分组、颜色、重命名、删除、资源记录删除、多选和常用右键操作已提供。删除资源记录会清除它在所有项目中的归属，删除项目只解除该项目的关联，两者都保留原文件。项目名与分组名分别保留原有的大小写不敏感唯一规则，名称仅用于展示和查找，不是永久身份；项目分组暂不支持嵌套。

WinUI 自动恢复在用户打开物理文件时执行，MCP 的 `get_resource` 也可显式触发同一恢复逻辑，依赖 Windows 可用的卷标识与 File ID。无法获取文件身份时，仍可按原路径正常打开，路径失效后则保留为「路径失效」。应用不扫描文件系统，不使用 FileSystemWatcher、后台监控、启动服务或 USN Journal，不自动跟踪文件夹条目改名，也不跟踪跨卷移动。

搜索只处理库内元数据，不读取文件内容，不使用 AI 或语义向量。当前不包含内容预览、标签、全局快捷搜索、云同步、账号、浏览器扩展、自动分类或服务端网络服务。网址收藏不导入浏览器书签，也不修改浏览器。应用面向单用户本地使用，允许多个本机 AI 客户端共用资源库，不提供多机器共享数据库或多设备协作方案。

主题跟随 Windows 深浅色设置，尚无应用内主题切换。Mica 背景效果取决于系统版本和设置。应用提供中英文操作提示与错误说明；Windows 返回的底层错误详情可能使用操作系统自身的语言。
